# 한자 튜터 (초등 한자 급수 학습·문해력 챗봇 PWA)

*Created At: 2026-11-04T07:53:32.134672+00:00*

## Goal

초등학생이 기관별(한국어문회 8~4급, 대한검정회 8~3급) 한자 급수 시험을 준비하도록 돕는다. 검수된 한자 DB를 바탕으로 오늘의 한자, 간격 반복 복습, 실전형 모의고사, 한국 기준 획순 따라쓰기 채점, 한자·어휘 주제로 제한된 안전한 문해력 챗봇을 제공한다. 학부모는 리포트, 학습계획, 대화 열람, 사용 시간 제한으로 자녀의 학습을 관리한다. 요금은 사용량 기반 무료 플랜과 구독(토스페이먼츠)으로 운영한다.

## User Stories

1. **As a** 급수 시험을 준비하는 초등학생, **I want to** 매일 앱을 열어 자주 쓰이는 순서로 제시되는 오늘의 한자를 배우고, 1·3·7·14일 간격으로 돌아오는 복습 문제를 푼다, **so that** 시험일까지 배정 한자를 무리 없이 나눠 익히고 잊기 전에 다시 복습할 수 있다.
2. **As a** 급수 시험을 준비하는 초등학생, **I want to** 선택한 기관·급수의 실제 시험과 같은 문항 수·유형·제한 시간으로 모의고사를 보고, 합격 여부와 틀린 문항 해설을 확인한다, **so that** 실전 감각을 익히고 약한 유형과 한자를 파악할 수 있다.
3. **As a** 급수 시험을 준비하는 초등학생, **I want to** 한자를 화면에 손가락이나 펜으로 따라 쓰고, 틀린 획은 그 자리에서 다시 쓴다, **so that** 한국 기준의 올바른 획순과 방향을 몸에 익힐 수 있다.
4. **As a** 급수 시험을 준비하는 초등학생, **I want to** 문해력 챗봇에게 한자와 어휘의 뜻을 묻고 지난 대화를 이어간다, **so that** 내 수준에 맞는 쉬운 설명으로 한자 어휘력을 키울 수 있다.
5. **As a** 급수 시험을 준비하는 초등학생, **I want to** 사용 시간이 끝나 잠긴 화면에서 부모에게 시간 연장을 요청한다, **so that** 공부를 마무리해야 할 때 부모 허락을 받아 계속할 수 있다.
6. **As a** 학부모, **I want to** 휴대폰 본인인증으로 가입하고 자녀 프로필(닉네임+PIN)을 만들며, AI 처리 동의 여부를 따로 선택한다, **so that** 자녀 개인정보를 법에 맞게 보호하면서 서비스를 쓸 수 있다.
7. **As a** 학부모, **I want to** 앱 안의 리포트와 주 1회 푸시 요약으로 학습 시간, 완료율, 정답률, 취약 한자, 모의고사 추이와 합격 가능성을 확인한다, **so that** 자녀의 학습 상태를 파악하고 필요한 지원을 할 수 있다.
8. **As a** 학부모, **I want to** 학습계획에서 하루 새 한자 수를 바꾸고, 하루 총 사용 시간과 사용 가능 시간대를 정하며, 추가 시간 요청을 승인하거나 거절한다, **so that** 자녀의 학습량과 기기 사용을 직접 관리할 수 있다.
9. **As a** 학부모, **I want to** 자녀의 챗봇 대화를 열람하고, 유해 표현이나 개인정보 입력이 있으면 알림을 받는다, **so that** 자녀가 챗봇을 안전하게 쓰고 있는지 확인할 수 있다.
10. **As a** 학부모, **I want to** 월간 또는 연간 구독으로 자녀 최대 3명이 유료 기능을 쓰게 하고, 필요하면 해지하거나 환불을 받는다, **so that** 여러 자녀에게 하나의 구독으로 전체 기능을 제공할 수 있다.

## Constraints

- 배포 가능한 PWA로 제공한다.
- 스택: Next.js(프론트엔드), PostgreSQL, Python FastAPI + LangChain/LangGraph(create_agent, create_supervisor).
- LLM은 어댑터 구조로 연결하며 기본 구현은 Bedrock ChatBedrockConverse를 쓴다.
- 결제는 토스페이먼츠로 처리한다.
- 지원 급수: 한국어문회 8~4급, 대한검정회 8~3급. 문항 수, 유형 구성, 제한 시간, 합격선은 기관·급수별 설정값으로 관리한다.
- 모든 한자 데이터는 검수된 한자 DB를 기준으로 한다. AI가 생성한 문제는 DB와 대조해 검증한다.
- 획순은 한국 기준을 따른다. 획순 검수가 끝나지 않은 글자는 모의고사 쓰기 문항으로 출제하지 않는다.
- 챗봇에서 DB에 없는 한자·어휘는 우리말샘 오픈 API로 검색해 답한다. 우리말샘에도 없으면 "잘 모르겠어요"라고 답한다.
- 날짜 경계(오늘의 한자, 복습, 일일 사용 시간)는 한국 시각(KST) 자정이다.
- 챗봇 대화 이력은 자녀 프로필당 최대 100개까지 저장한다. 초과하면 가장 오래된 대화부터 자동 삭제한다.
- 만 14세 미만 아동 정보 처리를 위해 가입 시 휴대폰 본인인증으로 법정대리인을 확인한다.
- 대화·학습 기록을 AI로 처리하는 데에는 별도 동의를 받는다.
- 챗봇 입력에 포함된 개인정보(주소, 전화번호 등)는 저장하지 않는다.
- 결제 기록은 전자상거래법에 따라 5년간 분리 보관한 뒤 삭제한다.
- 구독 1개당 자녀 프로필은 최대 3명이다.
- 요금제 가격은 설정값으로 관리한다(확정 전까지 하드코딩하지 않는다).
- 획순 채점의 위치·길이 허용치는 설정값으로 관리하며 라이브러리 기본값에서 시작한다.
- 축약판 모의고사는 제공하지 않고 실전형만 제공한다.

## Success Criteria

1. [가입·프로필] 부모가 휴대폰 본인인증을 완료해야 가입되고, 가입 후 닉네임과 PIN으로 자녀 프로필을 만들 수 있다.
2. [가입·프로필] AI 처리 별도 동의를 하지 않으면 해당 자녀의 챗봇 기능만 비활성화된다. 오늘의 한자, 복습, 모의고사, 따라쓰기는 정상적으로 쓸 수 있다.
3. [가입·프로필] 자녀 PIN을 5회 틀리면 프로필이 잠기고, 부모가 자신의 계정에서 PIN을 재설정하면 잠금이 풀린다.
4. [가입·프로필] 계정이나 자녀 프로필을 삭제하면 해당 자녀의 학습 기록과 챗봇 대화가 즉시 삭제된다. 결제 기록은 운영 데이터와 분리되어 5년간 보관된다.
5. [가입·프로필] 1년 동안 접속하지 않은 계정은 휴면 전환 30일 전에 안내를 받고, 이후 휴면 처리되어 데이터가 분리 보관된다.
6. [오늘의 한자] 하루 새 한자 수는 시험일까지 남은 배정 한자를 균등 분배해 자동 계산되며 하루 3~15자 범위를 벗어나지 않는다.
7. [오늘의 한자] 부모가 학습계획에서 하루 새 한자 수를 수정하면 그 값이 반영된다.
8. [오늘의 한자] 새 한자는 자주 쓰이는 한자부터 제시된다.
9. [오늘의 한자] KST 자정에 오늘의 한자와 복습이 다음 날 분량으로 바뀐다.
10. [오늘의 한자] 하루를 건너뛰면 다음 날 밀린 복습이 이어서 표시되고, 새 한자는 하루 분량만 제시되며, 남은 계획이 재계산된다.
11. [복습] 모의고사 오답 한자와 따라쓰기에서 정답 획을 본 한자가 자동으로 복습 목록에 추가된다.
12. [복습] 복습 목록의 한자는 1·3·7·14일 간격으로 다시 출제되며, 하루 복습 개수에는 상한이 없다.
13. [복습] 서로 다른 날 3회 연속 정답이면 '익힘 완료'로 처리되어 목록에서 빠진다.
14. [복습] 복습에서 틀리면 간격이 한 단계만 되돌아간다(예: 7일 → 3일).
15. [모의고사] 선택한 기관·급수의 설정값과 동일한 문항 수, 유형 구성, 제한 시간으로 출제된다.
16. [모의고사] 합격/불합격은 기관·급수별 실제 합격선으로 판정되어 표시된다.
17. [모의고사] 시험 중 앱을 이탈했다가 돌아오면 이어서 응시할 수 있다. 이탈 중에도 타이머는 멈추지 않으며, 제한 시간이 끝나면 자동 제출된다.
18. [모의고사] 결과 화면에 총점, 유형별 정답률, 틀린 문항 해설이 표시되고, 틀린 한자는 복습 목록에 자동으로 추가된다.
19. [모의고사] 한자 쓰기 문항은 힌트 없는 빈 칸에 직접 쓰는 방식이며 획순 데이터를 기준으로 채점된다.
20. [모의고사] 획순 검수가 끝나지 않은 글자는 쓰기 문항으로 출제되지 않는다.
21. [따라쓰기] 획마다 순서와 방향은 엄격히 판정하고, 위치와 길이는 설정된 허용치 안에서 너그럽게 판정한다.
22. [따라쓰기] 틀린 획은 그 자리에서 즉시 강조되어 다시 쓰게 하고, 같은 획을 3번 틀리면 정답 획을 보여준다.
23. [따라쓰기] 글자 단위 결과는 점수 없이 '통과/재시도' 두 단계로만 표시된다.
24. [따라쓰기] 서로 다른 날 2회 통과하면 그 한자의 쓰기 학습이 완료로 처리된다. 정답 획을 본 한자는 복습 목록에 추가된다.
25. [챗봇 주제 제한] 숙제 풀이 요청이나 게임·연예인 잡담에는 정중히 거절한 뒤 관련 한자어로 유도한다(예: 게임 → 승리(勝利)).
26. [챗봇 주제 제한] '학교'처럼 주제와 관련된 일상 질문에는 한자어로 풀어 답한다.
27. [챗봇 안전] 욕설, 폭력, 개인정보가 입력되면 응답을 차단하고 개인정보는 저장하지 않는다. 해당 건은 학부모 대화 열람 화면에 표시되고 학부모에게 알림이 간다.
28. [챗봇 안전] 같은 대화에서 유해·개인정보 입력이 3회 반복되면 그날 챗봇 대화가 잠긴다.
29. [챗봇 답변 품질] 답변은 학생의 목표 급수 안의 한자를 우선 사용하고, 급수 밖 한자에는 '상위 급수' 표시가 붙는다.
30. [챗봇 답변 품질] 답변은 초등 수준 어휘로 3~5문장이다.
31. [챗봇 답변 품질] 답변의 훈·음이 검수된 DB와 다르면 DB 값으로 교정되어 표시된다.
32. [챗봇 답변 품질] DB에 없는 한자는 우리말샘 오픈 API 결과로 답하고, 거기에도 없으면 "잘 모르겠어요"라고 답한다.
33. [챗봇 응답·오류] 답변은 스트리밍으로 질문 후 3초 안에 시작된다.
34. [챗봇 응답·오류] 15초가 지나거나 오류가 나면 "잠깐 문제가 생겼어요, 다시 물어봐 줄래요?" 문구와 다시 시도 버튼이 표시되며, 실패한 질문은 사용량에 포함되지 않는다.
35. [챗봇 대화 이력] 대화 이력이 저장되어 이어서 대화할 수 있다.
36. [챗봇 대화 이력] 프로필당 100개를 넘으면 가장 오래된 대화가 자동 삭제되고, 사용자가 대화를 직접 삭제할 수도 있다.
37. [사용 시간 제한] 부모는 하루 총 사용 시간과 사용 가능 시간대를 모두 설정할 수 있다.
38. [사용 시간 제한] 제한 5분 전에 예고가 표시되고, 제한에 도달하면 앱이 잠긴다. 모의고사 응시 중이면 끝까지 마친 뒤 잠긴다.
39. [사용 시간 제한] 잠긴 뒤 학부모 PIN을 입력하면 추가 시간을 줄 수 있다.
40. [사용 시간 제한] 학생이 잠금 화면에서 시간 연장을 요청하면 부모가 푸시로 받아 승인하거나 거절할 수 있다.
41. [학부모 리포트] 앱 안에서 일·주별 학습 시간, 오늘의 한자 완료율, 복습 정답률, 취약 한자, 모의고사 점수 추이와 합격 가능성, 쓰기 학습 완료 한자 수를 언제든 볼 수 있다.
42. [학부모 리포트] 주 1회 요약이 PWA 푸시로 발송된다.
43. [학부모 리포트] 부모가 자녀의 챗봇 대화를 열람할 수 있다.
44. [구독] 월간·연간 요금제가 설정값 가격으로 표시되고 토스페이먼츠로 결제된다.
45. [구독] 구독 1개로 자녀 프로필 최대 3명이 유료 기능을 이용할 수 있다.
46. [구독] 해지해도 결제 기간이 끝날 때까지 유료 기능이 유지된다.
47. [구독] 결제 후 7일 이내에 유료 기능을 사용하지 않았으면 전액 환불된다.
48. [구독] 자동결제가 실패하면 3일간 유예하면서 매일 재시도하고, 부모에게 푸시와 이메일로 알린다. 유예 기간이 끝나도 실패하면 무료 플랜으로 전환된다.

## Assumptions

- 월간·연간 요금제 가격은 미정이므로 설정값으로 두고 이후에 확정한다.
- 획순 채점의 위치·길이 허용치 수치는 정해지지 않았다. 사용하는 획순 라이브러리의 기본값으로 시작해 조정한다고 가정한다.
- '시험일까지 균등 분배'를 하려면 프로필에 목표 기관·급수와 시험일이 입력되어 있어야 한다. 입력 주체(학생 또는 부모)와 시험일 미입력 시의 기본 동작은 확정되지 않았다.
- '자주 쓰이는 순서'를 정할 빈도 데이터의 출처는 확정되지 않았으며, 검수된 한자 DB에 빈도 정보가 포함된다고 가정한다.
- '실패한 질문은 사용량에 포함하지 않음'은 챗봇 질문이 무료 플랜 사용량 측정 단위 중 하나라는 전제이다. 구체적인 사용량 기준은 아직 정해지지 않았다.
- 결제 실패 이메일 알림을 보내려면 부모 이메일을 수집해야 한다. 가입 시 이메일을 받는다고 가정하지만 명시적으로 확정되지는 않았다.
- 리포트의 '합격 가능성' 산출 방식(모의고사 점수 추이 기반 등)은 정해지지 않았다.
- 휴면 계정 분리 보관 이후의 최종 삭제 시점과 복귀 절차는 정해지지 않았다.
- 유해 표현·개인정보 탐지 방식(룰 기반, LLM 분류 등)과 '반복' 판정 기준(같은 유형인지, 유형과 무관하게 누적인지)은 확정되지 않았다.
- PWA 푸시 알림은 부모 기기와 브라우저가 웹 푸시를 지원하고 권한을 허용했다고 가정한다. 미지원·미허용 시 대체 알림 경로는 정해지지 않았다.
- 따라쓰기 '통과/재시도' 판정은 모든 획을 결국 올바르게 써야 통과인지, 정답 획을 본 경우 재시도로 처리하는지 명확히 정해지지 않았다.
